# SpaceX Falcon 9 First Stage Landing Prediction

## Project Overview
This project is part of the IBM Data Science Capstone. It explores SpaceX Falcon 9 launch data to investigate whether the first stage of a Falcon 9 rocket successfully lands.

## Objectives
- Collect and prepare launch data for analysis.
- Explore launch outcomes and relevant features.
- Perform SQL-based exploratory analysis.
- Build and evaluate machine learning classification models.
- Investigate factors associated with first-stage landing success.

## Notebook
**Machine Learning Prediction — Part 5**

The notebook covers model training, hyperparameter tuning, and evaluation of classification algorithms.

## Models
- Logistic Regression
- Support Vector Machine (SVM)
- Decision Tree
- K-Nearest Neighbors (KNN)
